## ⚙️ Scraper Setup & Usage

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

```bash
# Scrape today's date, update archives, project profiles, and README
python scrape_trending.py

# Filter by spoken language (e.g. 'en', 'zh')
python scrape_trending.py --lang en

# Write into a specific date archive
python scrape_trending.py --date 2026-08-01

# Re-scrape and force update
python scrape_trending.py --force
```

Daily updates are automated via [GitHub Actions](.github/workflows/daily-trending.yml).
